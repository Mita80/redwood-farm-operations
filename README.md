# redwood-farm-operations
Redwood Farm Operations — User Guide (README.md)
Redwood Farm Operations is a digital livestock‑management system designed to streamline pig production workflows, improve data accuracy, and support real‑time decision‑making at Redwood Farms.
Built using AppSheet and backed by secure cloud storage, the app centralizes all core operational processes into one unified platform.


🌿 Features
Livestock Management
Pig profiles (tag, breed, DOB, status)

Herd summaries and dashboards

Growth and health tracking

Daily Operations
Feeding logs

Medication and treatment records

Breeding cycle management

Mortality logs

Activity tracking for staff

Reporting & Insights
Automated summaries

Visual dashboards

Data‑driven decision support

🐖 Who This App Is For
Farm managers

Livestock supervisors

Veterinary staff

Feeding and breeding teams

Administrative personnel

Role‑based access ensures each user sees only the information relevant to their responsibilities.

📱 How to Use the App
1. Log In
Access the app through your AppSheet link provided by Redwood Farms.

2. Navigate the Dashboard
The dashboard provides quick access to:

Herd summary

Daily logs

Medication and breeding records

Mortality overview

3. Add or Update Records
Use the menu to:

Add new pigs

Log feed or medication

Record breeding events

Capture mortality details

4. Review Reports
Dashboards and summary views help track:

Herd performance

Health trends

Operational efficiency
